### 💻 Featured Projects

#### 🧠 RAG Agentic AI Chatbot

**Python • FastAPI • LangChain • LangGraph • ChromaDB • HuggingFace • OpenRouter**

An end-to-end Agentic AI chatbot that provides context-aware responses from a custom PDF knowledge base.

* Implemented document ingestion and text chunking
* Generated semantic embeddings using Sentence Transformers
* Used **ChromaDB** for persistent vector storage and similarity search
* Integrated LLMs through the **OpenRouter API**
* Built REST APIs using **FastAPI**
* Orchestrated the AI workflow using **LangGraph**

#### 🛡️ ProctoEase — Real-Time Online Proctoring Platform

**FastAPI • React • PostgreSQL • WebSockets • Docker**

A multi-tenant online assessment and proctoring platform with real-time monitoring and candidate integrity features.

* Implemented role-based workflows for **Admin, Recruiter, and Candidate**
* Built real-time violation detection using **WebSockets**
* Implemented tab-switching and fullscreen-exit detection
* Added face and multi-face detection workflows
* Built camera-snapshot pipelines for identity verification
* Added plagiarism detection and code evaluation
* Containerized the application using **Docker**
